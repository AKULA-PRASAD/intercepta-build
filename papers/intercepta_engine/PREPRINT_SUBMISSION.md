2. "Submit a manuscript" → new submission → paste Title + Abstract + category.
3. Add authors (names, affiliations, emails, ORCIDs); mark corresponding author.
4. Upload `MANUSCRIPT.pdf` as the manuscript file (+ figure files if prompted).
5. Choose license (see #2); answer the AI-use question (yes, disclosed).
6. Add the Data/Code availability statement (repo link).
7. Submit → bioRxiv screens in ~24–48 h → assigns a DOI and posts.

# INTERCEPTA Fullest Vision -- Synthesis Documents

**Charter reference:** fullest-vision-charter-v1.1

This directory holds synthesis documents that integrate findings from docs/research/literature/RESEARCH_LOG.md.

## Cadence (per charter §5.2)

- **Weekly syntheses:** WEEKLY_SYNTHESIS_YYYY-MM-DD.md covering the prior week's reading
- **Per-layer syntheses:** LAYER_N_SYNTHESIS.md at end of each research layer
- **Cross-cutting analyses:** topic-specific synthesis as needed

## Format

Each synthesis ends with:
1. Convergent findings (multiple sources agree)
2. Open conflicts (sources disagree, gap requires resolution)
3. Updated answers to research questions Q1-Q11
4. Recommended next reading
5. Charter amendments needed (if any)

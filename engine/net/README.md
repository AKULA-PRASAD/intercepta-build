# engine/net — multi-layer disease knowledge-graph builders
Builds graph layers (steps 1–14) from PUBLIC sources: STRING, KEGG, OpenTargets, ChEMBL, GTEx selectivity,
AlphaFold, metabolome, immune. Outputs are data → excluded from the repo (see ../../data/MANIFEST.md).
## HONEST STATUS
Real, working infrastructure that assembles known public biology into a graph. The founding "universal
15-layer net for ANY disease" is **aspirational scope**, not a validated capability. No novel biology is
discovered by graph assembly itself.
